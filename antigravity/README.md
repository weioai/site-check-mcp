# Weio site check for Google Antigravity

Antigravity plugin manifest for the hosted Weio site check MCP server (`https://weio.ai/mcp`). The tools, limits and terms are described in the [main README](../README.md). To use a paid key, add `"headers": { "Authorization": "Bearer wk_..." }` to the server entry in your own `mcp_config.json`.
