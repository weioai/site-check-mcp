# Security

Report security problems with the hosted server at `https://weio.ai/mcp`, the `weio.ai` API, or this repository to **sales@weio.ai** with "security" in the subject. Please do not open a public issue for a vulnerability.

We read every report, reply within two business days, and tell you when it is fixed. The server is read-only toward the websites it checks, refuses private networks, IP literals and non-standard ports, and stores API keys only as SHA-256 hashes.
